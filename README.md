# Heart Disease Prediction Using Decision Tree and Random Forest

## About Project
In this project, I used Decision Tree and Random Forest algorithms to predict heart disease using a heart disease dataset. The project was done in Jupyter Notebook using Python and Scikit-learn.

## Dataset
The dataset contains information about patients such as:
* Age
* Sex
* Cholesterol
* Blood Pressure
* Heart Rate
* Other medical details

Target column:
* target (0 = No Heart Disease, 1 = Heart Disease)

## Libraries Used
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Work Done
1. Loaded the dataset.
2. Checked dataset size and columns.
3. Split data into training and testing sets.
4. Trained a Decision Tree model.
5. Calculated model accuracy.
6. Visualized the decision tree.
7. Trained a Random Forest model.
8. Compared both models.
9. Checked feature importance.
10. Performed cross-validation.

## Result
Both models were able to predict heart disease successfully. Random Forest gave better and more reliable results compared to a single Decision Tree.

## Conclusion
This project helped me understand:
* Decision Trees
* Random Forests
* Feature Importance
* Overfitting
* Model Evaluation
